# HCB 知识工作台 v0.3

版本日期：2026-10-22。本版继续 v0.2 的四个视图：知识图谱、表血缘、指标血缘、标准模型宽表。

双击 `HCB_知识工作台_v0.3.html` 即可使用。该文件已内嵌数据、样式、脚本和原 Excel 基线，离线打开无需服务。`index.html`、`metrics.html`、`tables.html`、`models.html` 是兼容入口。

## 使用

- 默认显示 SI 与 POS 全貌；单击对象即高亮完整上下游并打开详情，普通选中不会自动缩放。
- “高亮范围”切换方向和层数；“仅看当前链路”隐藏无关对象；“清除高亮”保留筛选，“返回全貌”恢复初始范围。
- 知识图按四类知识分区和 26 个主题组织。双击主题展开，点击连线查看关系明细。
- 指标实线为直接依赖，虚线为带条件的计算路径，点线为业务规则派生。必售 SKU 门店数与 POS 门店数是限定口径下的门店集合资格筛选关系，不代表对汇总门店数直接做算术。
- 模型视图以建议模型为中心，显示现有资产与服务场景；点击模型可查看完整业务粒度、范围、归属、指标和维度。
- 对象清单可筛选、导出 CSV；SQL 原文可逐行查看；对象地址可以复制。

## 本次修复

## 仍保留的事项

页面待办共 4 项：2 项原资料问题、2 项 SQL 实现异常。实现异常交由数据开发核对运行影响和修复安排，已确认业务口径继续保留。本版只修知识展示与证据，不修改生产 SQL。

SI 统一实际数据范围继续包含 KE24 与 KE30 调整合并；Offline POS 包含当前组织归类下的线上分销。产品与门店增量公式、两套门店/SKU 识别口径沿用已确认版本。

Excel 下载仍为 `HCB_Offline_POS_知识补全版_20261015.xlsx` 原基线，字节未改；本次不是新一版指标或维度字典。
